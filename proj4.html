MODULE_02   TB TOPOLOGY

TESTBENCH ARCHITECTURE

Class-based environment communicating purely through mailbox handles. apb_env forks the agent and scoreboard; apb_agent forks the generator, BFM, monitor and coverage collector.

MODULE_03   OPERATION

VERIFICATION FLOW

⌘
GENERATE
  • apb_gen picks testcase from apb_common::testname
  • Randomizes PWRITE, PADDR, PWDATA
  • For read/write testcases, read address reuses the written PADDR
  • Pushed to gen2bfm mailbox
▶
DRIVE
  • apb_bfm gets tx from gen2bfm
  • Drives PADDR, PWRITE, PWDATA through SETUP → ACCESS
  • Asserts PSEL / PENABLE, waits for PREADY
  • Captures PRDATA on reads, increments bfm_count
◈
SAMPLE
  • apb_mon is a passive, pin-to-transaction observer
  • Captures a transfer when PENABLE && PREADY
  • Reconstructs the APB transaction from bus activity
  • Broadcasts to mon2scb and mon2cov
✓
CHECK
  • apb_scb keeps a reference_mem[*] shadow model
  • On write: reference_mem[PADDR] = PWDATA
  • On read: compares PRDATA to reference_mem[PADDR]
  • Updates matching / mismatching
⬡
COVER
  • apb_cov owns two covergroups — cg_tx, cg_vif
  • cg_tx: PADDR auto-bins + PWRITE HIGH/LOW + cross
  • cg_vif: PSEL × PENABLE cross with an illegal bin
  • Sampled per transaction from mon2cov
MODULE_04   TESTPLAN

DIRECTED TESTCASES

TC_01
1W
Single randomized write transaction. Baseline sanity check for one SETUP → ACCESS handshake.
Sequence: write ×1
TC_02
5W
Five randomized write transactions, exercising the generator/BFM loop under fixed repetition.
Sequence: write ×5
TC_03
NW
N randomized write transactions, where N is set in apb_common.sv (default 8).
Sequence: write ×N
TC_04
1WRD
One write followed by one read to the same address — a directed read-after-write check.
Sequence: write(addr=A) → read(addr=A)
TC_05
5WRD
Five writes followed by five reads back to the same addresses, scaling up the read-after-write pattern.
Sequence: write(addr) ×5 → read(addr) ×5
TC_06
NWRD
Default testcase. N writes across the address space, then N reads of the same addresses — full read-after-write closure, 100% coverage.
Sequence: write(addr) ×N → read(addr) ×N
⚙ Selected via apb_common::testname (default "NWRD") and apb_common::N (default 8) in apb_common.sv.
MODULE_05   PROTOCOL CHECKS

SVA ASSERTIONS

Four protocol properties live in apb_assert.sv, checking the APB handshake independent of which testcase is running.

NO_ENABLE_WITHOUT_SELp1
!PSEL |-> !PENABLE
PENABLE must never be asserted while the slave is not selected.
PREADY_SIGNALS_STABLEp2
(PSEL && PENABLE && !PREADY) |=> $stable(PADDR)
While waiting in ACCESS, address must hold stable into the next cycle.
PENABLE_LOW_B4_SETUPp3
(PENABLE && PREADY) |=> !PENABLE
PENABLE must drop the cycle after a completed transfer, before the next SETUP.
PRDATA_NO_UNKNOWNp4
!$isunknown(PRDATA)
Read data must never resolve to an unknown (X) value during simulation.
